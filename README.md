# fms_frontend

Production baseline General product UI

## Scaffold Summary

- App type: Frontend
- Stack: React + Vite + TypeScript
- Routing: react-router
- Styling: tailwind
- UI add-on: shadcn-ui
- State: context
- Data fetching: fetch
- Testing: vitest

## Setup

```bash
npm install
npm run dev
```

## Notes

- This project starts from a Vite React TypeScript baseline.
- The scaffold then applies the selected routing, styling, data, and testing choices.
